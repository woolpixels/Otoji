# Otoji · 提取与拼接音频

本地音频处理工具。

从视频里提取声音，或把几段音频重新排好顺序接在一起。  
所有处理都在本机完成，不上传文件，断网也能用。

> Otoji 不是完整的音频编辑器，它只专注于「提取」和「拼接」。

## 主要功能

### 提取音频

从视频中提取声音并导出为 MP3。

支持：

- MP4
- MOV
- M4V

可以：

- 查看音频波形
- 设置开始与结束时间
- 试听选区
- 使用 128 / 192 / 320 kbps 三档音质
- 查看预计文件大小
- 将提取结果直接送入「拼接音频」

默认导入后会将结束时间设为视频末尾前 3 秒，方便去掉短视频常见的片尾。

---

### 拼接音频

把多段音频重新排序并合并成一个 MP3。

支持导入：

- MP3
- M4A
- WAV
- FLAC
- OGG

可以：

- 拖动调整顺序
- 连续试听
- 设置片段之间的静音间隔
- 单独调整某一个间隔
- 一次导出完整 MP3

拼接时会重新编码，避免直接拼接 MP3 时常见的片段间空隙。

## 使用流程

### 从视频提取音频

1. 拖入一个视频
2. 调整开始与结束位置
3. 试听确认
4. 选择音质
5. 导出 MP3

导出完成后，可以：

- 直接试听
- 在访达中查看
- 返回调整
- 另存一份
- 送入音频拼接

### 拼接音频

1. 拖入多段音频
2. 调整顺序
3. 设置片段间隔
4. 连续试听
5. 导出合并后的 MP3

## 快捷键

在提取音频时：

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `I` | 将播放位置设为开始 |
| `O` | 将播放位置设为结束 |
| `⌘S` | 导出 |

---

## 文件保存

桌面版导出的文件默认保存到：

`下载`

如果已有同名文件，会自动添加序号，例如：

`audio (2).mp3`

---

## 隐私

Otoji 不需要账号，也没有服务端。

- 不上传视频
- 不上传音频
- 不保存你的文件到云端
- 音频解码、处理与编码均在本机完成
- 离线状态下也可以使用
